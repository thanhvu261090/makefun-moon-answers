# The Moon Finally Answers Back

Entry for the [make.fun bounty "The Moon Finally Answers Back"](https://make.fun/bounty/u-mang-the-moon-finally-answers-back-781a7ec1): one line, 1–240 characters, in the voice of the Moon replying at last to the wishes, howls and late-night promises of everyone staring up at it.

## Entry

> Four billion years of your wishes, howls, and 2 a.m. promises -- and not one of you has ever once wished me goodnight back.

123 characters.

## How it works

`main.py` writes the entry line to `/output/entry.txt` (or the path in `ENTRY_OUTPUT`) and prints it. The entry is a fixed string, so every run writes byte-identical output. Run the self-test with:

```sh
python3 main.py --self-test
```
